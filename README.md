SPANISH
Solo debemos abrir la carpeta pyronet desde un computador, descargar todos sus archivos y guardarlos en la misma carpeta todos los archivos, la carpeta se debe llamar pyronet, luego para poder abrir pyronet debemos ejecutar el archivo que se llama Lanzar_pyronet.bat, no se preocupen por que windows lo marque como archivo peligroso, no contiene ningún malware y solo descarga los datos que son necesarios para correr el sistema de PYRONET.
 En caso que la carpeta Pyronet falle, dirigirse a la carpeta history y descargar los archivos de la carpeta lanzamiento, siguiento el mismo orden de guardarlos en la misma carpeta y corriendo el archivo PYRONETSTART, nuevamente no se preocupen por las alertas de windows.

ENGLISH
To set up the system, open the pyronet folder from a computer, download all the files, and save them together in a single local folder named pyronet. Next, run Lanzar_pyronet.bat to launch PYRONET. Please disregard any Windows security alerts flagging the file as potentially dangerous—it is completely safe, contains no malware, and solely downloads the data required to run the PYRONET system.
If you encounter any issues with the Pyronet folder, please navigate to the history folder and download the files from the lanzamiento folder. Follow the same process by saving them all into a single folder and running the PYRONETSTART file. Once again, please disregard any Windows security alerts
